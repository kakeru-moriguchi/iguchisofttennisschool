# 画像の置き場所

このフォルダに画像ファイルを置くだけで、サイトの写真が差し替わります。
**コードを触る必要はありません。**

画像がまだ用意されていない場所には、自動的に仮のプレースホルダーが表示されます。
同じファイル名で画像を置けば、そのまま本物の写真に切り替わります。

## 画像を用意するときのポイント

- **形式**：`.jpg` を推奨（写真の場合）。`.png` や `.webp` も使えますが、
  その場合は `data/` フォルダ内のファイルで拡張子を変更してください。
- **容量**：1枚あたり 500KB 以下を目安に。表示速度が速くなります。
  （Next.js が自動的に WebP / AVIF へ変換・最適化します）
- **比率**：多少違っても構いません。自動的に中央を基準に切り抜いて表示されます
  （`object-fit: cover`）。ただし、被写体が端に寄りすぎている写真は
  切れてしまうことがあるため、中央付近に配置された写真をおすすめします。

## 写真を追加・変更したいとき

ファイル名やパスを変えたい場合は、以下のファイルを編集してください。

- クラス画像 … `data/classes.ts` の `image`
- スクール紹介の写真 … `data/school.ts` の `galleryPhotos`
- 講師の写真 … `data/instructors.ts` の `image`
- ファーストビュー … `data/site.ts` の `heroImage`
